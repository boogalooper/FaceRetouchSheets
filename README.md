# FaceRetouchSheets

Скрипт собирает лица из фотографий на общие листы для передачи ретушеру. После обработки второй скрипт возвращает фрагменты в исходники Photoshop.

## Сборка листов

- Поиск одного или нескольких лиц в PSD, TIFF и JPG, включая вложенные папки.
- Прямоугольник вокруг лица с запасом под шею. Размер запаса настраивается.
- Сохранение фрагментов в исходном размере, без масштабирования.
- JPG с максимальным качеством или TIF со сжатием без потерь. По умолчанию JPG.
- Максимальная ширина и высота листа задаются отдельно, до 12 000 px. При необходимости создаются дополнительные листы.
- Работа на GPU или CPU. В режиме «Авто» при недоступности CUDA используется CPU.
- Сохранение последней папки, формата, устройства, запаса под шею и размеров листа.
- Прогресс обработки и отмена кнопкой или Esc.
- Передача папки аргументом командной строки. Доступен режим обработки без интерфейса.

Результат сохраняется в папку `_face_retouch`. Вместе с листами создаются карта координат `face-map.tsv` и отчёт `scan-report.tsv`. В отчёте отмечаются ошибки, кадры без найденных лиц и пересечения прямоугольников.

Листы сохраняются в RGB 8 бит с профилем sRGB. Для PSD используется сохранённый композит Photoshop с максимальной совместимостью. Запас под шею рассчитывается по размеру лица, поэтому готовые листы стоит просмотреть перед отправкой.

## Возврат ретуши в Photoshop

`photoshop/ImportFaceRetouch.jsx` запускается для открытого исходника.

- Находит карту и соответствующие листы по пути исходного файла.
- Вставляет каждый фрагмент отдельным слоем точно в исходные координаты.
- Использует Action Manager для обрезки, переноса и позиционирования.
- Проверяет размеры документа и вставленных слоёв.
- Закрывает лист после копирования последнего нужного фрагмента.
- Завершается без диалога об успешной вставке.
- Объединяет вставку в одно действие истории. При ошибке возвращает документ к состоянию до импорта.

После ретуши листы сохраняются под теми же именами, с теми же размерами и расположением фрагментов. При пересечении прямоугольников может потребоваться маска слоя.
